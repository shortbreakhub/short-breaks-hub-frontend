# Issue #98 — owner-approved country gateway fallback

Decision date: 2026-10-12. Country gateway approval is a business-policy decision supported by physical airport identity and established passenger operations. It is not verification of a door-to-door travel plan, live Trip.com inventory, flight frequency or airport proximity to the itinerary.

## Outcome

- 201 canonical keys, unchanged six-field runtime schema and AIRPORT location type.
- **198 VERIFIED / 3 REVIEW_REQUIRED / 0 UNAVAILABLE**.
- All previous 130 VERIFIED runtime and evidence records unchanged.
- 71 previous REVIEW_REQUIRED records reviewed: **8 defensible local airports retained**, **60 country-entry gateways approved**, **3 Myanmar safety exceptions retained**.
- 27 airport-code changes applied within those 71 records under the owner-approved policy. All 60 country fallbacks are GATEWAY, never DIRECT.
- No itinerary arrival text, Hotel mapping, affiliate URL builder, application UI or lookup logic changes.

## Airport selection

Existing local passenger airports retained: Mendoza MDZ, Chengdu TFU, Guilin KWL, Luang Prabang LPQ, Vientiane VTE, Cusco CUZ, Bohol TAG, Washington IAD. Existing operating-airline research suffices; ground-transfer gaps are no longer blockers. TFU is corroborated by operating-airline passenger offers rather than conflating it with CTU.

Country fallback prefers an operational capital international entry point: Brasília BSB, Wellington WLG, Phnom Penh KTI, Beijing PEK, Kuala Lumpur KUL and the other capital-serving airports shown below. For national/territorial primary-gateway exceptions, the reason is recorded separately: Fiji NAN instead of the capital's Nausori domestic hub; South Africa JNB rather than a local Pretoria airport; Tanzania DAR as the established main international entry rather than an unverified Dodoma international-arrival option; Switzerland ZRH rather than treating limited/unestablished Bern entry suitability as a confirmed broad gateway. New Caledonia uses its own NOU, not mainland France. These choices do not promise suitability from every origin.

The BSB physical reference was cross-checked against the existing airport-code registry and operating-airline airport information; it is a physical BR airport, not a metropolitan code. ACC is labelled **Accra International Airport**, following the current operator name; the physical code is unchanged. Previously verified records remain untouched.

## Evidence boundaries

Previously approved passenger evidence was reused for the same physical airport. Existing local-airport observations were reused where operations had already been established. Only missing gateway identity/operations facts were checked with airport operators, operating airlines or national tourism; no broad onward-transport research was restarted. Source observations distinguish retrieved content from indexed excerpts and reused approvals. A source that failed retrieval was not treated as proof of airport unsuitability. New sources support passenger entry, not unspecified ferries, safari lodges, island flights or regional road transfers.

Country-level gateways may require a further domestic flight, ground transfer or ferry. Those arrangements are outside this dataset's current approval criteria. Existing itinerary recommendations remain separate and were reviewed in [itinerary-mapping-consistency.md](itinerary-mapping-consistency.md). A downstream interface must not call a country gateway the local airport or imply the traveller has reached the itinerary destination.
